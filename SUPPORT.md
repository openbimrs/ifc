# Support

## Documentation and questions

Start with the [documentation](https://openbimrs.github.io/ifc/) and the
[evidence-backed capability matrix](https://openbimrs.github.io/ifc/capabilities).
For usage questions, design discussion, and ideas that are not yet concrete bug
reports, use [OpenBIM.rs Discussions](https://github.com/orgs/openbimrs/discussions).

## Bugs and feature requests

Use the repository's issue forms:

- [bug report](https://github.com/openbimrs/ifc/issues/new?template=bug_report.yml);
- [feature or enhancement](https://github.com/openbimrs/ifc/issues/new?template=feature_request.yml);
- [papercut or ergonomics issue](https://github.com/openbimrs/ifc/issues/new?template=papercut.yml).

Check the [public roadmap](https://github.com/orgs/openbimrs/projects/1) and
existing issues before filing a duplicate.

## Contributing work

Use the [Ready for contributors](https://github.com/orgs/openbimrs/projects/1/views/3)
view. Each promoted implementation issue links to its stable `PLAN.md` task and
required evidence. See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.

The project does not currently offer private implementation support or a
response-time SLA. Security reports follow [SECURITY.md](SECURITY.md), not the
public issue tracker.
