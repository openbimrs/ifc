# ifc-style

Presentation as borrowed views over `ifc-model`: colours, surface and curve
styles, textures, layers, styled items and annotation, resolved through the
schema of the file's release. Styles reference geometry but never change its
shape.

```bash
cargo add ifc-style
```

The [`openbim-ifc`](https://crates.io/crates/openbim-ifc) facade also provides it behind its
`style` feature.

- API documentation: [docs.rs/ifc-style](https://docs.rs/ifc-style)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-style)
- Source and issues: [github.com/openbimrs/ifc](https://github.com/openbimrs/ifc)
