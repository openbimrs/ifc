# OpenBim.Ifc

The API reference of the `OpenBim.Ifc` NuGet package: read, edit, validate
and write IFC (STEP and ifcXML) files from .NET, over the versioned C ABI of
the `openbim-ifc` Rust core. Generated by docfx from the assembly's XML
documentation comments.

- [`IfcModel`](xref:OpenBim.Ifc.IfcModel): parse, query, edit, validate and
  write a model.
- [`Value`](xref:OpenBim.Ifc.Value): an attribute value, a closed set of
  records.
- [`AuthorOp`](xref:OpenBim.Ifc.AuthorOp): one operation of a checked
  authoring batch.
- [`IfcException`](xref:OpenBim.Ifc.IfcException) and
  [`IfcStatus`](xref:OpenBim.Ifc.IfcStatus): how a refused call reports why.
- [Every type](xref:OpenBim.Ifc) in the `OpenBim.Ifc` namespace.

For task-sized examples, see the [.NET guide](/ifc/bindings/dotnet) and the
[.NET cookbook](/ifc/cookbook/dotnet).
