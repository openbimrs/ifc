# ifc-classification

Classification systems and references, documents, libraries and their object
associations, read as borrowed views over `ifc-model` against the release the
file declares (IFC2X3, IFC4 or IFC4X3), with transaction-staged authoring in
that release's layout. No query performs external I/O.

```bash
cargo add ifc-classification
```

The [`openbim-ifc`](https://crates.io/crates/openbim-ifc) facade also provides it behind its
`classification` feature.

- API documentation: [docs.rs/ifc-classification](https://docs.rs/ifc-classification)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-classification)
- Source and issues: [github.com/openbimrs/ifc](https://github.com/openbimrs/ifc)
