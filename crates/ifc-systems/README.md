# ifc-systems

Distribution systems as borrowed views over `ifc-model`: systems and zones,
ports and their attachment to elements, the port connection graph with
cycle-safe traversal, flow roles and direction, and the buildings and
facilities a system serves, plus authoring for systems, ports and their
relationships.

```bash
cargo add ifc-systems
```

The [`openbim-ifc`](https://crates.io/crates/openbim-ifc) facade also provides it behind its
`systems` feature.

- API documentation: [docs.rs/ifc-systems](https://docs.rs/ifc-systems)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-systems)
- Source and issues: [github.com/openbimrs/ifc](https://github.com/openbimrs/ifc)
