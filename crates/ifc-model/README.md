# ifc-model

The IFC entity graph: storage, structural queries, traversal budgets and
checked mutation, free of domain semantics and serialization. Entities the
build does not understand still round-trip unchanged, and codecs plug in
through the `Codec` trait this crate owns.

```bash
cargo add ifc-model
```

- API documentation: [docs.rs/ifc-model](https://docs.rs/ifc-model)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-model)
- Source and issues: [github.com/openbimrs/ifc](https://github.com/openbimrs/ifc)
