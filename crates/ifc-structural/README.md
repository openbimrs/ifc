# ifc-structural

Bounded structural-analysis semantics across IFC2X3, IFC4 and IFC4X3: analysis
models, load and result groups, idealized members and connections, actions and
static loads, as schema-resolved borrowed views with selected
transaction-staged authoring. It does not solve structures or generate FEM
meshes.

```bash
cargo add ifc-structural
```

The [`openbim-ifc`](https://crates.io/crates/openbim-ifc) facade also provides it behind its
`structural` feature.

- API documentation: [docs.rs/ifc-structural](https://docs.rs/ifc-structural)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-structural)
