# ifc-spatial

Spatial containment and objectified-relationship traversal: the project, site,
building, storey and element tree, element relationships and space boundaries,
read from the relationship entities with the correct slot for each.

```bash
cargo add ifc-spatial
```

The [`openbim-ifc`](https://crates.io/crates/openbim-ifc) facade also provides it behind its
`spatial` feature.

- API documentation: [docs.rs/ifc-spatial](https://docs.rs/ifc-spatial)
- Reference page: [openbimrs.github.io/ifc](https://openbimrs.github.io/ifc/reference/crates/ifc-spatial)
- Source and issues: [github.com/openbimrs/ifc](https://github.com/openbimrs/ifc)
