# ifc-geometry authoring: closing the remaining gaps

Status at start: 86 entity types authored, 68 flagged by `/tmp/geogap2.py`.

## Triage of the 68

`/tmp/triage.py` splits them three ways:

- **16 authored in their owning crate already** -- the detector flags them
  because `ifc-geometry` *reads* them, not because anything is missing.
  `IfcProject`/`IfcSIUnit`/`IfcUnitAssignment` (ifc-properties, ifc-spatial),
  the material usages (ifc-material), the representation contexts
  (ifc-georef), `IfcAlignment`/`IfcLinearPlacement` (ifc-alignment),
  `IfcWall` (several). Authoring them here would duplicate a writer that
  already exists behind the right crate boundary. **Not doing these.**

- **4 instantiable-but-meaningless supertypes** -- `IfcLoop`, `IfcVertex`
  have zero attributes; `IfcProfileDef` and `IfcGeometricSet` carry only
  what every subtype restates. EXPRESS does not mark them ABSTRACT, so a
  writer is legal, but a bare `IFCLOOP` denotes nothing. **Skipping, and
  saying so** rather than shipping writers nobody can use correctly.

- **48 genuine gaps**, batched below.

## Batches

Each: probe schema -> write -> round-trip through the real reader ->
refusal tests -> mutation sweep -> gate -> commit -> push. One commit per
batch, as established for profiles/tessellation/CSG/curves/swept/brep.

### 5. Surfaces (7)
`IfcBSplineSurfaceWithKnots`, `IfcRationalBSplineSurfaceWithKnots`,
`IfcSphericalSurface`, `IfcToroidalSurface`, `IfcCurveBoundedPlane`,
`IfcCurveBoundedSurface`, `IfcRectangularTrimmedSurface`.

Invariants: **two** knot identities (U and V), each
`sum(mult) = degree + |ctrl| + 1` along its own axis; the control grid
must be rectangular. `IfcRectangularTrimmedSurface` has real WHERE rules:
`U1 <> U2`, `V1 <> V2`, and `Vsense = (V2 > V1)` -- a writer that lets the
caller pass an inconsistent sense produces a surface trimmed backwards.

### 6. Profiles (7)
`IfcArbitraryOpenProfileDef`, `IfcArbitraryProfileDefWithVoids`,
`IfcCenterLineProfileDef`, `IfcCompositeProfileDef`,
`IfcDerivedProfileDef`, `IfcMirroredProfileDef`,
`IfcRoundedRectangleProfileDef`.

Traps: `IfcMirroredProfileDef` redeclares `Operator` as **DERIVE** -- `*`,
not `$`, the same class as `IfcOrientedEdge`. `ValidRadius` bounds the
rounding radius by half of each dimension. `IfcArbitraryProfileDefWithVoids`
requires `ProfileType = AREA` and forbids an `IfcLine` inner curve.

### 7. Transformation operators and mapping (7)
The four `IfcCartesianTransformationOperator` forms, `IfcRepresentationMap`,
`IfcMappedItem`, `IfcTopologyRepresentation`.

### 8. Surface curves (10)
`IfcPcurve`, `IfcSurfaceCurve`, `IfcIntersectionCurve`, `IfcSeamCurve`,
`IfcCompositeCurveOnSurface`, `IfcBoundaryCurve`, `IfcOuterBoundaryCurve`,
`IfcCurveSegment`, `IfcReparametrisedCompositeCurveSegment`,
`IfcGradientCurve`.

`IfcBoundaryCurve` carries `IsClosed : SELF\IfcCompositeCurve.ClosedCurve`
-- the one place `ClosedCurve` is not free to be UNKNOWN.

### 9. Placement, connection, grid, sets (17)
`IfcLocalPlacement`, `IfcGridPlacement`, `IfcGridAxis`, `IfcGrid`,
`IfcVirtualGridIntersection`, the five `IfcConnection*Geometry` forms,
`IfcGeometricSet`, `IfcGeometricCurveSet`, `IfcPath`, `IfcPointOnCurve`,
`IfcPointOnSurface`, `IfcBooleanClippingResult`, `IfcSectionedSpine`,
`IfcConversionBasedUnitWithOffset`.

## Standing rules

- Kernel-free: no Axiolid type named, verified by
  `cargo test -p ifc-geometry --no-default-features`.
- Reuse the `pub(crate)` slot modules in `src/surface/`, `src/curve/`,
  `src/resource/`; relocate rather than duplicate if one is feature-gated.
- Stage new files OUT of tree until wired -- the module-reachability gate
  fails on an unreferenced `.rs`.
- `cargo clippy --workspace --all-targets --all-features` before every
  gate run; unused imports have cost several gate cycles.
- Commit `docs/` alongside: `sync-capabilities.py` regenerates it and
  leaving it out failed CI on d3edb6c.
