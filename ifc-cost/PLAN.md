SLOT-FIX - cargo test -p ifc-cost (20 passing) - the shipped slot constants were
wrong: IfcCostItem/IfcCostSchedule inherit ObjectType from IfcObject and declare
PredefinedType, so Identification is 5 and CostValues is 7, not 4 and 5. The
crate's own unit fixtures encoded the same wrong layout, so its tests passed.
Verified by dumping attribute names from IfcOpenShell rather than counting the
EXPRESS listing by hand. Regression test asserts the real STEP layout.

COST-RATE - cargo test -p ifc-cost (20 passing) - IfcAppliedValue.Components
forms a tree with ArithmeticOperator; a component tree is evaluated in schema
order, and an operator that is absent on a parent with components is reported
rather than assumed to be ADD.

COST-REL - cargo test -p ifc-cost (20 passing) - nesting is IfcRelNests
(RelatingObject 4 / RelatedObjects 5) and assignment is IfcRelAssignsToControl
(RelatingControl 6, after IfcRelAssigns' RelatedObjects 4 and
RelatedObjectsType 5). Both traversals carry a cycle budget and report the
offending path.

COST-UNIT - cargo test -p ifc-cost (20 passing) - currency comes from
IfcMonetaryUnit as a free-text code; a file stating two different codes is
Ambiguous rather than resolved by picking one. Rollup refuses to add values
whose currencies disagree.

COST-CORPUS - cargo test -p ifc-cost (20 passing) - test/fixtures/
synthetic-cost-schedule/synthetic_cost_schedule.ifc, generated by
